## Backend capability probes

- `tests/archive/closed-backend-probes/c500_fdot2_probe.cpp/.py`：真实C500 compile capability为`f16=0 bf16=0`，当前`xcore1000`工具链没有暴露packed FP16/BF16 dot→FP32 accumulator。
- `tests/archive/closed-backend-probes/c500_pk_fma_bf16_probe.cpp/.py`与`tests/archive/closed-backend-probes/c500_pk_fma_f16_probe.cpp/.py`：对应builtin在`xcore1000`编译阶段被拒绝，要求`xcore1500`或更高target feature；不绕过架构限制。
- `tests/archive/closed-backend-probes/c500_bx_cast_probe.cpp/.py`：`b0..b3_cast_to_f32`是little-endian unsigned byte→FP32，不是BF16解包；例如`0x01020304 -> [4,3,2,1]`。
- `tests/archive/closed-backend-probes/c500_update_shfl_probe.cpp/.py`：`update_shfl`是masked destination update，不是shuffle+add融合；四级allreduce仍有4次shuffle和4次fadd，资源/机器码不优于普通mov。
- `tests/archive/closed-backend-probes/c500_raw_shfl_probe.cpp/.py`：官方CUTE `mov_raw_shfl`与普通`mov_shfl`对生产mode逐lane等价，四级allreduce和机器码大小不变，MTreg反而`2→3`。

这些是独立后端能力探针，不是生产候选源码。它们共同关闭“只替换builtin名称即可减少case11 QK指令”的路线；除非MACA版本、target feature或硬件证据发生变化，不重试。
